## Limitations

- **CI**: first push surfaced real first-run defects (workflow DSN
  interpolation, `gofmt` drift, lint unused vars, and three genuine
  zoom/narrow-viewport layout overflows). All were repaired and the
  suite is now **PASS** on the pushed head (`b11174b`, run
  `39719204692`: go-quality, go-integration, web-quality,
  staged-secrets-self-test all green).
- **License**: `licenseInfo: null`; no LICENSE file — owner decision pending.
- **Publication/hosted**: blocked on owner prerequisites listed above;
  the distribution and hosted gates CANNOT pass without them.
- **Media**: localRC captures only; production-path media deferred until
  a real hosted deployment exists.
- **Scanner**: govulncheck reported one unmaintained-package advisory
  (`x/crypto/openpgp`) that is provably absent from the shipped binary —
  retained as a documented false positive, not silently dropped.
- Engine capacity telemetry under fault injection is non-gating where
  the injected fault did not touch the relevant backend (recorded in
  the acceptance doc).
